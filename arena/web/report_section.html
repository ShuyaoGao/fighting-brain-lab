REAL GAMES

接入真实街机游戏的路线

这台实验台用的是自带的小街机。框架本身与游戏解耦：环境、人类条件包装器、自博弈联赛、利用者、评估都只依赖一套统一的逐帧输入接口，换游戏只换一份配置。接真实游戏的常见路线：

路线适合条件代价
stable-retro（开源，MIT）已有现成集成的主机版格斗游戏Linux / macOS；ROM 自备集成里通常有血量地址，可能缺坐标和 2P 存档
DIAMBRA Arena它支持的几款街机格斗游戏需要 Docker；ROM 自备环境现成，但游戏列表固定
FBNeo / MAME 自建集成任意街机游戏Linux；ROM 自备要自己找 RAM 地址（血量、坐标、回合、计时）、做 1P/2P 存档，每款约 1–3 人日

无论哪条路线：ROM 必须是自己合法拥有的副本（本项目不提供、不下载 ROM）；真实模拟器比这台小街机慢一两个数量级，训练要放到 Linux 服务器上跑；评估时仍然要加上人类级反应延迟和手速上限，否则"打赢人类"没有意义。

详见仓库 docs/LANDSCAPE.md（格斗游戏强化学习的环境、论文与工具调研）和 envs/retro_adapter.py、envs/diambra_adapter.py。
