# 格斗大脑实验台（arena）

浏览器里的"对局 + 大脑"双屏：一边是游戏，一边是 AI 神经网络的实时可视化。离线可用，不需要 GPU，也不需要 Python（免安装版）。

## 启动

```powershell
.\.venv\Scripts\python -m arena                  # 导出模型 → 生成页面 → 本地服务 → 自动开浏览器
.\.venv\Scripts\python -m arena --layout single  # 右栏默认只显示一个大脑
.\.venv\Scripts\python -m arena.build --release  # 免安装版：play/（双击 index.html）+ release/格斗大脑实验台-v1.0.zip
.\.venv\Scripts\python -m arena.build --dist     # 静态版 arena/dist/（不带 HTML 骨架，用于嵌入其他页面）
```

也可以直接双击 `arena/web/index.html`（先跑过一次 `python -m arena.export` 或 `python -m arena`）。

## 布局规范（所有涉及神经网络的项目通用）

- **左右两栏**：左栏上方是游戏画面，下方依次是对手、播放、敲除、招式表等选项和说明（可滚动）；右栏只放大脑，占满整个高度。不再出现"上方游戏、下方大脑"的布局。
- **右栏顶部切换**「P1 大脑 | P2 大脑 | 全部」：
  - 单个模式：完整显示一个网络（输入层逐行、隐藏层展开最重要的若干个神经元 + 全层方阵、连线、输出概率、局势评估、归因）。
  - 全部模式：所有智能体的大脑在右栏里上下堆叠，每个用紧凑但完整的画法——输入按组聚合（活跃度 + 归因）、隐藏层画全层热力方阵、输出列概率最高的几个动作和局势评估；边框用该玩家的阵营色并标明是谁；点击某一个切到它的单个模式。
  - 按 N 个智能体设计（不写死 2 个）：N ≤ 2 上下堆叠；N = 3–4 时右栏够宽（≥ 1100 px）排成 2×2，不够就堆叠加滚动。
- **大屏模式**：右栏顶部的开关把左右比例从约 45:55 调成约 35:65，投影时把大脑放大。
- **窄屏（手机、竖屏平板，≤ 980px）**：变成一栏，顺序是游戏 → 大脑 → 选项与说明；游戏画布按宽度等比缩放；大脑默认「全部」的紧凑画法，宽度 < 600px 时改成自上而下的手机画法，每个约 430px 高；说明浮层占满宽度、可上下滚动、「知道了，开始」按钮固定在底部；触屏设备上键盘示意图换成虚拟按键说明；虚拟按键只在「我来打」「练习」里出现，放在画面下方。验收：`python -m arena.browser_check` 额外模拟 390×844、414×896（DPR 3）和 768×1024（DPR 2）的触屏手机。
- **标清每一层的个数**：大脑顶部写结构式，例如「输入 214 → 隐藏 512 → 隐藏 512 → 输出 31 个动作 + 1 个局势评估 · 参数 761,888」，数字从实际模型读取；每一层上方写个数和显示方式（输入 214 维 = 游戏状态 90 + 最近 4 次动作 124；隐藏层 1：512 个神经元，展开对当前决策贡献最大的 32 个，下方方阵是全部 512 个；输出 31 个动作 + 1 个局势评估）。
- **退出**：右上角「退出」停止游戏主循环、定时器和手柄轮询，关闭 AudioContext，断开键盘与手柄监听，释放模型数据，然后尝试关闭窗口；关不掉时显示结束页。用 `python -m arena` 打开时，还会调用本地服务的 `/shutdown`；页面每 5 秒发一次心跳，服务超过 30 秒没收到心跳（标签页已关闭）会自动退出。离线版是纯静态网页，没有后台进程。

## 三种玩法与新手引导

| 玩法 | 内容 |
|---|---|
| 观战（打开时默认） | 两个 AI 自动对打，右栏「全部」模式显示两颗大脑；顶部标签「我来打」切到人机对战 |
| 我来打 | 你操作 P1（蓝）。对手预设四档：新手 / 普通 / 困难 / 无限制，旁边写明是什么网络、Elo 多少；「按网络大小挑选」里仍可用滑块自选 |
| 练习 | 对手是木桩（站着不动 / 只防御 / 只跳 / 会出拳），不计时、自动回血；任务清单（宽屏在右栏，窄屏在游戏下方）逐项打勾：前进、后退、跳、蹲、站防、蹲防、轻攻击、重攻击、气功波、冲天拳 |

新手引导（`assets/coach.js`）：
- **操作说明浮层**：第一次打开时弹出，之后按 <kbd>H</kbd> 或右上角「?」再打开；含键盘示意图。
- **招式表**：鼠标停在招式上，按顺序点亮方向键（例如 ↓ ↘ → + J），并按你当前的朝向显示实际要按的键（朝右时 S、S+D、D、J；朝左时左右互换）。
- **输入历史栏**：画面左侧显示最近的方向和按键（数字是按住的帧数）；放出必杀技时闪「气功波 ✓」，没放出来时提示差在哪（少了 ↘、方向太慢、按键晚了、场上已有气功波……）。判定规则与游戏核心相同：三个方向在 15 帧内，最后一个方向在按键前 5 帧内。
- **新手模式**（默认开）：<kbd>U</kbd> 气功波、<kbd>I</kbd> 冲天拳，按住 <kbd>Shift</kbd> 放重版本（手柄 LB / RB）。实现方式是把 AI 动作空间里同一个「搓招宏」（↓↘→+攻击、→↓↘+攻击，4 帧）原样按出来，每一下方向和按键照样计入手速，所以与 AI 的条件一致。

招式显示名和角色外观集中在 `envs/fighting2d/naming.json`，改名、换配色只改这一处（内部标识 `fireball_L`、`236L` 不变）。署名与系列信息在根目录 `credits.json`，页脚从这里读取。

## 画面上每样东西是什么

| 区域 | 内容 | 依据 |
|---|---|---|
| 游戏画面 | JS 版游戏核心（`assets/fight.js`），与 Python 训练环境逐帧一致；角色骨架动画、火花、震屏、音效都是纯视觉，不改游戏状态 | `tests/test_js_parity.py`（状态 + 事件逐帧对拍） |
| 半透明人影 | AI 此刻"看到的"世界（开启反应延迟时，是 12 帧 = 200ms 前的画面） | `BrainPlayer` 的观测缓冲区 |
| 输入层 | 输入 214 维 = 游戏状态 90 + 最近 4 次动作 124。90 维游戏状态按"自身/对手/帧数据/飞行道具/相对距离"分组，名称来自 `envs/fighting2d/obs_spec.py`；独热组（13 种状态、11 种招式）合并成一行小方格；左边条 = AI 看到的值，白线/白框 = 此刻真实值；右边条 = 归因 | `tests/test_obs_spec.py` 逐维比对名称与 `core.observe` |
| 自己最近的动作 | 观测里的 124 维动作历史（最近 4 次 × 31 个动作），合并成一个节点 | `wrappers/frame_skip.py: ActionHistory` |
| 隐藏层 | 每个圆点一个神经元，颜色 = 激活（橙正、蓝负）；宽层只展开对本次决策最重要的 K 个（K 随面板高度变化，图上注明 "展开 K/宽度"），下面的小方阵是整层全部神经元 | 重要度 = ∂log π(a)/∂h × h |
| 连线 | 只画贡献最大的若干条：输入→第 1 层 70 条、层间 60 条、最后一层→所选动作 24 条；贡献 = 前一层激活 × 权重 | `brain.js: edgeContrib` |
| 输出层 | 31 个动作的概率（中文名），黄色 = 实际选择（按概率采样） | 与训练时同一策略 |
| 局势评估 | 价值头（critic）的输出，以及本回合的价值曲线 | `final.pt` 里的 critic 权重 |
| 归因 | 默认"梯度 × 输入"，可切换"积分梯度"（16 步，基线 = 全零观测）；都是对 log π(所选动作) 求导。**这是相关性解释，不是因果** | `tests/test_arena_brain.py` 对拍 torch 梯度、检验积分梯度完备性 |
| 敲除 | 点任意神经元把它的激活置零（红叉），再点恢复；"敲掉关键神经元"按敲除实验的结果一键敲掉（金框） | 与 Python `NumpyPolicy(masks=...)` 一致 |

## 模型

`arena/export.py` 从 `runs/scaling/*/seed*/final.pt`（规模实验）和几个旧实验的 `final.pt` 读出**真实训练权重**（actor + critic），每个模型一个 JS 文件按需加载。界面上用"家族（人类条件/无限制/旧实验）+ 宽度滑块 + 深度 + 种子"选模型，也可以从下拉框直接选。

## 免安装版

`python -m arena.build --release` 生成：
- `play/`：完整 HTML、13 个精选模型（float16）、本地字体（`arena/fonts.py` 按页面用到的字符取子集，以 data URI 打包，SIL OFL 1.1）、演示录像。在 `file://` 下全部可用（资源都用 `<script>` 加载，不用 fetch），也能原样放到 GitHub Pages。
- `release/格斗大脑实验台-v<版本>.zip`：同一份内容打包，挂到 GitHub Release。

`python -m arena.browser_check` 用本机 Chrome 和 Edge 打开 `play/index.html`，在 1920×1080 和 1366×768 下逐项验收（左右两栏、「全部」与单个模式切换、大屏模式、结构式数字与模型一致、退出按钮、说明浮层、本地字体、观战、双脑/单脑、敲除、我来打、键盘、手搓气功波、新手键、搓错提示、练习任务、无横向滚动、无脚本错误）。

## 录像与自动化测试

`arena/capture.py` 用本机已装的 Chrome/Edge（无头模式 + DevTools 协议）驱动页面：

```powershell
.\.venv\Scripts\python -m arena.capture shot --out shot.png --layout dual --frames 400
.\.venv\Scripts\python -m arena.record --all      # 三段演示：人类 vs AI（脚本模拟按键）、大 vs 小、敲除前后
.\.venv\Scripts\python -m pytest tests\test_arena_browser.py
```
