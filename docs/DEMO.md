# 课堂演示脚本（5 分钟）

主线：**观战 → 看它在想什么 → 换成小网络 → 敲掉神经元 → 请同学上手**。备用：「实验报告」标签页。

## 开场前（1 分钟准备）

- 免安装版：解压 `格斗大脑实验台-v1.0.zip`（或仓库里的 `play/` 目录），双击 `index.html`。不需要 Python，不需要联网。
- 从源码启动：`python -m arena`（导出模型 → 本地服务 → 自动打开浏览器，默认 http://127.0.0.1:8765）。
- 投屏 1920×1080：浏览器全屏（F11）。1366×768 的笔记本也能用，布局会自动收缩。
- 第一次打开会弹出操作说明，点「知道了，开始」；之后按 <kbd>H</kbd> 或右上角「?」随时再打开。
- 音效：第一次点页面后才会出声（浏览器规定）。手柄插上即可用。

## 0:00–1:00　观战

1. 页面打开就是两个 AI 自动对打（默认 P1 = 困难档 512×2，P2 = 普通档 128×2）：左边是游戏，右栏上下两颗「大脑」（「全部」模式）。投影时打开右栏的「大屏模式」，大脑会更大。
2. 讲：这是一台 60 帧的小街机，规则按帧算（发生、持续、收招）；网页里的游戏核心和 Python 训练环境**逐帧一致**（有自动化对拍测试）。两个 AI 都是在「200ms 反应 + 每分钟 600 次操作」的人类条件下训练的。

## 1:00–2:15　看它在想什么

1. 点「暂停」，再点「单帧 ▸」几下；点右栏里的 P2 大脑（或顶部「P2 大脑」）切到完整画法，先指着顶部的结构式讲「输入 214 → 隐藏 128 → 隐藏 128 → 输出 31 个动作 + 1 个局势评估」，再分区讲：
   - **左列输入层**：网络看到的 90 个输入，每行是真实特征名；左边的条是 **AI 看到的值**，白线是**此刻的真实值**——两者不一样，因为它有 200ms 反应延迟。画面里的半透明人影就是「它看到的世界」。
   - **中间隐藏层**：圆点颜色 = 激活（橙正蓝负），只展开对这次决策贡献最大的几十个，下面的小方阵是整层；连线只画贡献最大的若干条。
   - **右列输出**：31 个动作的概率，黄色是它实际选的；上方仪表是价值头的「局势评估」，下面是这一回合的价值曲线（挨打时往下掉）。
   - **底部一句话**：这次决策主要被哪些输入推动（梯度 × 输入）。强调：这是**相关性解释，不是因果**。
2. 速度调到 0.25× 继续播放，让同学看到「对手一出招 → 输入里『对手判定中』亮起 → 防御类动作概率升高」。

## 2:15–3:15　换成小网络

1. 在 P2 面板展开「按网络大小挑选」，把宽度滑块拉到最左（8）。比赛自动重开。
2. 讲：两边训练方式、步数、人类条件完全一样，只差网络大小（参数 38.9 万 vs 2 千）。循环赛里 512 宽对 8 宽平均得分 98%；整条曲线是 Elo −92 → 733（秩相关 0.80），但主要是 128 → 256 那一跳，小网络之间种子差距很大。
3. 再把 P1 换成「无限制」档（0ms 反应、不限手速）：最小的无约束网络对最大的人类条件网络得分 81%。**限制反应和手速，比把网络缩小 90 倍影响还大。**

## 3:15–4:00　敲掉神经元

1. 右栏切到「P2 大脑」，P2 从模型下拉框选「64×2 · 人类条件 · 种子 2」（做过敲除实验的模型，金框标出梯度重要度前 32 的神经元）。
2. 先现场点一两个神经元敲掉（红叉），说明单个神经元几乎没影响。
3. 点「敲掉标注的神经元」，再点「全部恢复」；然后「随机敲掉 25%」做对比。
4. 讲定量结果（实验报告「敲除」一节）：逐个敲掉 128 个神经元，最大下降只有 5.4%，筛选出的前 8 个复核后只剩 −0.9%～2.4%（赢家诅咒）；一起敲 32 个，按重要度挑 29%、随机挑 26%，差不多——**这个网络没有单个关键神经元，信息是分散存储的**。都是相关性，不是因果。

## 4:00–5:00　请同学上手

1. 点顶部的「我来打」，对手选「新手」。
2. 新手模式默认打开：<kbd>U</kbd> 气功波、<kbd>I</kbd> 冲天拳。解释公平性：AI 的动作空间里本来就有这 4 个「搓招宏」，每一下照样计入手速。
3. 想练手搓：顶部切「练习」，木桩站着不动；把鼠标停在招式表的「气功波」上，看方向键按顺序点亮；画面左侧的输入历史会显示按了什么，搓错时提示差在哪。
4. 收尾：切到「实验报告」最上面的结论框——在人类反应和手速条件下，「RL 必然打得过职业选手」目前没有证据；要回答它，需要真实游戏 + 真人盲测 + 利用者打不穿。

## 出问题时

| 现象 | 处理 |
|---|---|
| 双击后用记事本打开了 | 右键 `index.html` →「打开方式」→ 选浏览器 |
| 键盘没反应 | 先切到「我来打」或「练习」，再点一下游戏画面让它获得焦点 |
| U / I 没反应 | 检查「新手模式」是否勾选 |
| 画面卡 | 关掉「积分梯度」；或者右栏只看一个大脑 |
| 讲完了 | 点右上角「退出」：所有计算停止；关掉标签页即可 |
| 从源码启动时端口被占用 | `python -m arena --port 9000` |
